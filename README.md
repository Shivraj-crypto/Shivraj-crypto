### 🔥 SmartScrapeV8 — AI Deal Extraction Pipeline
> **Python · Scrapling · Gemini API · Heuristic NLP**

A production-grade scraping engine with an intelligent, **heuristic-first architecture**. Scrapes e-commerce pages, runs domain-aware multi-language parsers, scores candidates by confidence, and only falls back to Gemini AI when heuristics are insufficient — minimizing API cost while maximizing accuracy.

- ✅ Multi-language coupon/deal detection (EN, CN, KR, JP, ES, PT)
- ✅ Structured field extraction: offer type, coupon code, discount %, expiry, store
- ✅ Excel batch mode with configurable throttling & error cooldown
- ✅ Dual-pass extraction: DOM container scan + line-by-line text analysis
- **2 forks** — others are building on this

### 🎯 Military-based Missile Impact Detection System
> **Python · YOLOv3 (self-trained) · OpenCV · GPS · Google Maps API**

- ✅ Self-trained YOLOv3 model (custom dataset)
- ✅ Dual input: physical camera or virtual (OBS) stream
- ✅ Real-time GPS impact localization using camera FOV math
- ✅ Email alert system with cooldown to prevent spam
- ✅ Modular architecture: detector, GPS service, alert service, cursor mapper
